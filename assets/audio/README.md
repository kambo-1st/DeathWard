# DeathWard audio — first playable pack

Original synthesized effects and ambient soundscapes generated by this project's
`scripts/generate_audio.py`. No external recordings, game rips, speech or music
are used. Monster families currently share a projectile effect and attack-warning cue.

The pack contains 30 mono 44.1 kHz PCM16 WAV effects and four stereo Ogg/Vorbis
ambience loops, each 16 seconds long. Frequently repeated shots, impacts and
footsteps have three variants. The mixer adds slight pitch variation to effects;
pickup, room-clear and test chimes retain their tuning.

- **Town:** soft wind and occasional wood creaks.
- **Frontier:** foliage/water-like noise and bird chirps.
- **Canyon:** low wind gusts with sparse distant wildlife.
- **Mine:** low air movement and irregular drips.

Footsteps use location-specific boot, gravel and mine-floor sounds. Imported
town navigation has no surface-material tags, so it does not distinguish every
individual wooden deck from dirt.

To regenerate, install `numpy`, `scipy` and `soundfile` in a development Python
environment, then run `python3 scripts/generate_audio.py`. The normal C++ build
uses checked-in files and requires none of these Python packages. The generator
uses its own fixed seed and never touches gameplay randomness.

WAV transients stay below full scale; ambience is intentionally quiet. The game
applies master/category gain, rate limits and a soft limiter to the final stereo
mix. raylib converts source audio to the output device's sample rate.
