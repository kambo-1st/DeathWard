# Expedition plan completion audit

Specification: [Isaac expedition study](isaac_expedition_study.md), its six-milestone implementation order, and the preserved goal instructions. Audit date: 2026-10-24. This checks the complete scope, including earlier milestones after the milestone-6 changes. The [implementation log](expedition_implementation.md) records commits, measurements and validation history.

| Requirement | Implementation and evidence |
| --- | --- |
| Configurable opening near nine rooms, growing later floors | `ExpeditionPlan::roomsOnFloor` supplies 9–15 schedules. Current `expedition`, `expedition_pacing` and `generated_room_graphs` tests cover actual counts, all 4–8-floor lengths, topology and dynamic indices. |
| Shorter early corridors and smaller ordinary rooms, measured separately | Five reversible presets remain. `docs/research/deathward-pacing-trials.csv` contains all 50 completed trials; `scripts/measure-expedition-pacing.cpp` reproduces the controller. Compact was selected from those measurements. Current pacing tests cover sizes, entrances, population, navigation and size-pool exhaustion. Later gameplay additions do not make the historical timings current player-performance claims. |
| Bomb-destructible scenery and optional cache | Separate runtime cracked rocks, seams, barrels and reinforced cache gates have stable IDs, collision/state and finite loot. Current destruction tests cover pre-blast snapshots in both iteration orders, source permissions, delayed barrels, deterministic loot, revisits, protected cache interiors and 256 actual floor layouts. Rendered props use the same live state for visible geometry/shadows and picking. |
| Six new build-changing items with explicit interactions | Scatter, Rail, Lodestone, Return, Cap and Braid are playable. The current item suite checks forms, body/wall interaction, guidance, two-leg return, blast provenance, bounded chains and 66 unordered pairs including duplicates, both acquisition orders and mouse/arrow inputs. [Item rules](expedition_items.md) record caps and deliberate exceptions. |
| Four floor identities and progression independent of room depth | Profile bands depend on expedition floor number. Current progression tests cover 64 actual band/seed floors, threat/specialist budgets, deterministic formations, safe entrances, ordinary navigation and the boss dodge loop. Scenery, breakable mix and restrained dust vary by band. |
| First complete canyon boss and two additional bosses | Ridgeback, Powder Foreman and Storm Marshal each have warning/attack/recovery behavior and phase changes. Tests exercise cover interruption, marked charges, contact kicks, committed aiming, sweep gaps, follow-up warnings, pause and death cleanup. Eighteen actual starting-revolver victories cover three seeds × early/final floors × three bosses without items, player dynamite or invulnerability. The seeded pool is checked over 512 plans; no immediate repeats occur. |
| Three optional room functions and distinct reward pools | Exchange, Surgeon and Smuggler use a small seeded subset inside the existing room budget. The economy suite checks all pool memberships, deterministic pairs, finite purchases, exact health previews including Judas, mutually exclusive choices, revisits and carry-over. Native and browser UI tests exercise the rendered menus and actual purchase controls. |
| Keys/dynamite have competing uses without trapping the player | Modern canyon boss approaches use combat gates; ordinary keys buy armory access or dynamite. Dynamite can be used in combat, demolition, caches or a finite coin exchange. The economy suite checks **98 actual floors** spanning all five expedition lengths, with every mandatory boss/evidence route reachable at zero keys and zero dynamite. Trading cannot alter this free graph. |
| No currency conversion loop | Each exchange is limited once per offer. Dynamite resale returns less than its shop price; keys/items have no reverse sale. Repeated attempts and revisits are tested. Boss supply/item rewards pay once, including debug replay. Campaign-persistent money is preserved; normal repeated expeditions can still earn money intentionally. |
| Preserve tutorial, story integration and 4–8-floor expeditions | The Lost Survey stays one floor/five rooms. Scheduled Survey Camp, Split Rock, Railway Cutting and Dry Creek remain inside normal floor budgets. Current story/campaign tests and the complete native arrival/testimony input traversal verify the tutorial, Rourke's multi-floor route, evidence gates, journal and Eleanor return. Existing unsupported testimony constructors remain unsupported; Cole is never designated objective truth. |
| Keep changes reversible and Classic available | Classic is retained in the menu/CLI and uses the original geometry, locks, final groups and five-item selection. The freshly generated ten-seed layout CSV is byte-identical to `docs/research/deathward-floor-size-sample.csv`. Each completed milestone has its own commit. |
| Preserve Original rendering, combat readability and both platforms | Original is still the default; no new whole-map filter was added. Boss silhouettes, charge fuses, sweep gap and exact-cost menus were visually inspected in native/browser captures. Native Release and WASM Release builds pass without compiler warnings. Full native CTest: **33/33 pass**. Browser boss/phase/weak-build checks and resource-purchase checks pass; the broad browser regression passes combat, audio, travel, persistence and editor flows. |
| Use and retain the preserved Isaac research | The implementation uses pool/stage separation as a reference, with original DeathWard effects, prices and bosses. All **193** preserved payload hashes still match the inventory. Re-running the analyzer against the preserved data produces a byte-identical aggregate report. Research files remain excluded from the game package. |

The complete native input suite, native arrival/story traversal, full focused browser boss/economy suite and broad browser regression have now passed. All six milestones are complete and documented in their own commits. This file does not claim final human balance testing: scripted trials establish reproducibility, feasibility and regression coverage. The boss pool is deliberately limited to three identities, and normal saves resolve interrupted expeditions rather than resuming a mid-floor scene.
